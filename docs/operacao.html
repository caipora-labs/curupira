04 / OPERAÇÃO

Valide, execute, acompanhe

Os três comandos usam o mesmo arquivo de configuração e o mesmo fluxo de execução.

Validar

Confere TOML e referências sem executar uma automação.

opscli validate

Executar uma tarefa

Seleciona a primeira tarefa disponível e espera a CLI terminar. A linha de status se reescreve no terminal e não entra no arquivo de log.

opscli run

Pré-visualizar

Mostra a seleção sem reservar cron, gravar estado, clonar ou executar.

opscli run --dry-run

Acompanhar continuamente

Consulta todas as automações e despacha tarefas conforme ficam disponíveis. A linha de status se reescreve no terminal e não entra no arquivo de log.

opscli watch

Selecione outro TOML

O padrão é ~/.opscli/settings.toml. A opção pode vir antes do comando:

opscli --config ./settings-dev.toml validate
opscli --config ./settings-dev.toml watch

Execução e arquivos locais

  • Somente um processo run ou watch pode despachar tarefas por vez.
  • Checkouts são exclusivos: duas tarefas que usam o mesmo caminho rodam em sequência.
  • Sessões interrompidas são salvas em ~/.opscli/state.sqlite3 e retomadas por watch após reiniciar.
  • Logs de texto são acrescentados em ~/.opscli/logs/opscli.log, com horário, repositório, tipo, ID e resultado da tarefa.
  • O exportador de traces OTLP/HTTP é opcional; configure settings.otlp_endpoint para ativá-lo.
