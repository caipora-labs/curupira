01 / INSTALAÇÃO

Prepare o ambiente

O gh-dispatch coordena CLIs locais. Instale somente os providers que pretende configurar.

Requisitos

  • Python 3.11 ou mais recente.
  • uv ou pipx para instalar a aplicação.
  • GitHub CLI (gh) instalado e autenticado.
  • A CLI usada no perfil selecionado: opencode, codex, claude ou agent (Cursor).
gh auth login

Instale o gh-dispatch

Com uv, instale como ferramenta isolada:

uv tool install gh-dispatch

Ou use pipx:

pipx install gh-dispatch

Confirme que o comando está disponível:

gh-dispatch --version

Crie as configurações

Por padrão, o programa lê ~/.gh-dispatch/settings.toml. Para começar com o exemplo do repositório: 

mkdir -p ~/.gh-dispatch
curl -fsSL https://raw.githubusercontent.com/mariotaddeucci/gh-dispatch/main/gh-dispatch.example.toml \
  -o ~/.gh-dispatch/settings.toml

Windows PowerShell

New-Item -ItemType Directory -Force "$HOME\.gh-dispatch"
Invoke-WebRequest `
  -Uri https://raw.githubusercontent.com/mariotaddeucci/gh-dispatch/main/gh-dispatch.example.toml `
  -OutFile "$HOME\.gh-dispatch\settings.toml"

Edite o TOML e troque os repositórios, consultas e prompts de exemplo pelos seus. O diretório central também contém o estado e os logs. Para selecionar outro arquivo, use --config caminho/para/settings.toml.
