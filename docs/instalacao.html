01 / INSTALAÇÃO

Prepare o ambiente

O gh-dispatch coordena CLIs locais. Instale somente os providers que pretende configurar.

Requisitos

  • Python 3.11 ou mais recente.
  • uv para instalar a aplicação.
  • GitHub CLI (gh) instalado e autenticado.
  • A CLI usada no perfil selecionado: opencode, codex, claude ou agent (Cursor).
gh auth login

Instale o gh-dispatch

O pacote ainda não está publicado no PyPI. Instale diretamente do repositório com uv:

uv tool install git+https://github.com/mariotaddeucci/gh-dispatch.git

Confirme que o comando está disponível:

opscli --version

Crie as configurações

Por padrão, o programa lê ~/.opscli/settings.toml. Para começar com o exemplo do repositório: 

mkdir -p ~/.opscli
curl -fsSL https://raw.githubusercontent.com/mariotaddeucci/gh-dispatch/main/opscli.example.toml \
  -o ~/.opscli/settings.toml

Windows PowerShell

New-Item -ItemType Directory -Force "$HOME\.opscli"
Invoke-WebRequest `
  -Uri https://raw.githubusercontent.com/mariotaddeucci/gh-dispatch/main/opscli.example.toml `
  -OutFile "$HOME\.opscli\settings.toml"

Edite o TOML e troque os repositórios, consultas e prompts de exemplo pelos seus. O diretório central também contém o estado e os logs. Para selecionar outro arquivo, use --config caminho/para/settings.toml.
