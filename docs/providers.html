03 / PROVIDERS

Flags nativas e retomada

O OpsCli chama cada ferramenta com a interface não interativa própria dela e salva o identificador de sessão para retomar uma tarefa interrompida.

O

OpenCode

Executa opencode run --format json.

  • model → --model provider/model.
  • agent → --agent, selecionando um custom agent já configurado.
  • effort → --variant.
  • Retoma uma sessão existente com --session <session_id>.
C

Codex

Executa tarefas não interativas com codex exec --json.

  • model → --model.
  • agent → --profile, usando um perfil de configuração Codex existente.
  • effort → --config model_reasoning_effort=<nível>; não existe uma flag --reasoning-effort.
  • Retoma o ID de thread com codex exec resume <thread_id>.

Níveis documentados: low, medium, high, xhigh, max e ultra. A disponibilidade depende do modelo e da versão do cliente.

C

Claude Code

Executa claude -p --output-format stream-json --verbose.

  • model, agent e effort são enviados por --model, --agent e --effort.
  • Retoma uma sessão salva com --resume <session_id>.
  • Os eventos JSON em streaming fornecem o ID da sessão e o texto da resposta.
C

Cursor

Usa o executável agent com --print --output-format stream-json.

  • model → --model.
  • agent escolhe o modo nativo por --mode: agent, ask ou plan.
  • effort não é suportado e é rejeitado na validação.
  • Retoma uma sessão salva com --resume <session_id>.

Sem configurar model, agent ou effort, o OpsCli omite as flags correspondentes e mantém as políticas nativas da CLI.
