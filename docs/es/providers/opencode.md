# OpenCode

Ejecuta `opencode run --format json`, pasando el modelo, el agente y el esfuerzo configurados como `--model`, `--agent` y `--variant`. Reanuda las sesiones con `--session <session_id>`.

| Opción | Argumento nativo |
| --- | --- |
| `agent` | Agente personalizado mediante `--agent` |
| `model` | `--model` opcional |
| `effort` | `--variant` opcional |
