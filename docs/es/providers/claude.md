# Claude Code

Ejecuta `claude -p --output-format stream-json --verbose`, pasando el modelo, el agente y el esfuerzo configurados mediante sus flags nativos. Reanuda con `--resume <session_id>`.

| Opción | Argumento nativo |
| --- | --- |
| `agent` | Agente personalizado mediante `--agent` |
| `model` | `--model` opcional |
| `effort` | `--effort` opcional |
