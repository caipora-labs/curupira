# Cursor

Executa `agent --print --output-format stream-json`, passando o model com `--model` e o modo com `--mode`. Retoma com `--resume <session_id>`. Effort não é suportado.

| Opção | Argumento nativo |
| --- | --- |
| `agent` | Modo via `--mode` (`agent`, `ask` ou `plan`) |
| `model` | `--model` opcional |
| `effort` | Não suportado; rejeitado |
