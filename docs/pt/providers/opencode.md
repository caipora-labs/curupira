# OpenCode

Executa `opencode run --format json`, passando o model, o agent e o effort configurados como `--model`, `--agent` e `--variant`. Retoma sessões com `--session <session_id>`.

| Opção | Argumento nativo |
| --- | --- |
| `agent` | Agente personalizado via `--agent` |
| `model` | `--model` opcional |
| `effort` | `--variant` opcional |
