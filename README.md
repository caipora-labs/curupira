# Curupira

Curupira runs local automations for developers: it dispatches GitHub tasks and cron
schedules, to local AI coding agents.

Install the Rust CLI from npm or PyPI. The npm package is scoped as
`@caipora-labs/curupira`; both installs provide `curupira` and `curu` and share `~/.curupira/`:

```bash
npm install -g @caipora-labs/curupira
pip install curupira
```

The user documentation and the PyPI package description live in
[packages/curupira-cli-py/README.md](packages/curupira-cli-py/README.md).
The npm package is [packages/curupira-cli-js/README.md](packages/curupira-cli-js/README.md).
Contributor and workspace notes are in [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).
