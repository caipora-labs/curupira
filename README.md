# Curupira

Curupira runs local automations for developers: it dispatches GitHub, Azure DevOps, Trello,
and monday.com tasks, plus cron schedules, to local AI coding agents.

The user documentation and the package description live in
[packages/curupira-python/README.md](packages/curupira-python/README.md).
Contributor and workspace notes are in [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).
